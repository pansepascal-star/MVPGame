# 残響の継承者

具現体を選んで戦う、ブラウザ向けのオリジナル能力バトルRPGです。3体の具現体はそれぞれ異なるアバター、技、戦闘特性を持ちます。

## 遊び方

`index.html` をブラウザで開いてください。

- 画面上部で具現体を選択。選び直すとバトルがリセットされます
- **玻璃の拳士**: 攻守のバランス型
- **雷鎖のヴァルカン**: 俊敏型。敵から受けるダメージを軽減
- **星喰いのアルカ**: 重撃型。大ダメージを与えるが、受けるダメージも増加
- **連撃**: 安定したダメージを与え、共鳴エネルギーを1得る
- **固有必殺技**: 共鳴エネルギーを2消費し、具現体ごとの大技を放つ
- **受け流す**: 次の敵の攻撃を軽減し、共鳴エネルギーを1得る
- **精神統一**: 共鳴エネルギーを2回復する（最大5）

選んだ具現体固有の技を使い、敵の予告を見ながら朔夜と具現体「虚空の重奏」に挑みましょう。

## 1v1サッカー

`soccer.html` を開くと、サイド視点の1v1サッカーを遊べます。WASDまたは矢印キーで移動し、ボールに近づくと自動でキープしてドリブルします。スペースキー（スマートフォンではシュートボタン）でシュートし、CPUと60秒間の得点を競います。
